## Contract and invariants

- Same active department/room only; real Queue ticket room/patient/appointment are rechecked at request and acceptance. No cross-specialty/room transfer in this workflow. No automatic rebooking or Queue reset.
- DOCTOR currently responsible requests; receiver must be a different active eligible doctor. Medical coordinator can initiate an exceptional request with reason when the owner cannot. ADMIN only manages the explicit coordinator capability for real doctor profiles; cannot read/sign clinical handovers as administrator.
- Receiver has only the dedicated handover summary until acceptance, not general consultation write access. Receiver alone accepts/rejects; current owner/initiator or explicitly granted active same-room/department coordinator may cancel a pending request with a reason and actual actor. Persist actor/time/reason/SBAR and decisions.
- One pending request per consultation; acceptance atomically changes responsibility and records history. Request/accept replays are idempotent; cancelled/rejected/changed-owner/closed cases cannot be accepted. Per-doctor transactional locks prevent simultaneous active consultations and serialize acceptance against new starts; optimistic version protects clinical writes against handover races.
- Keep Consultation.doctorId and original doctor snapshot as author. Add responsibleDoctorId/name. Response doctorId/name resolves current responsibility for existing authorization consumers; add explicit authoredByDoctorId/name so original authorship remains available. Document additive fields and current-doctor semantics in contract v1.2.
- Lab order/toa authors are never overwritten. Receiver may read existing clinical resources and review existing labs; cannot sign/update a draft authored by someone else. Create a new own draft when needed. Closed records remain immutable by handover.
- Queue remains room-scoped operational dispatch; calledBy preserves who called the patient. Handover does not create/check-in/complete/reorder a Queue entry. Same-room receiver already has the operational room scope. Appointment completion validates current Consultation responsibility where original booking doctor differs. EMR/Patient keep existing assignment authorization.
