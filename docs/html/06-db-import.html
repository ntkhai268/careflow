Nạp CSDL Clinical RAG & Kịch Bản Demo Khám Bệnh

Tài liệu súc tích, trực diện dành cho nhóm CareFlow để thiết lập CSDL Vector trong 2 giây, khởi chạy đúng các microservice và tự tin trình diễn toàn bộ tính năng AI (Voice STT + RAG Bộ Y Tế + Tương tác thuốc DDI).

1 Cách Nạp CSDL RAG: Dùng SQL Dump vs. JSON File

Kho tri thức RAG của CareFlow gồm 4 phác đồ Bộ Y Tế được chia thành 1.095 chunks với vector 768 chiều. Có 2 cách để nạp:

CÁCH 1: KHUYÊN DÙNG (2 GIÂY)

Dùng Tệp SQL Dump

Tệp scripts/careflow_ai_schema_and_data.sql (~9.5 MB) đã chứa trọn vẹn cả bảng, chỉ mục HNSW/GIN và 1.095 vector nhúng sẵn.

docker exec -i careflow-ai-postgres psql -U careflow -d careflow_ai < scripts/careflow_ai_schema_and_data.sql

✓ Nạp 1 phát ăn ngay, không cần cài Python hay token API.

CÁCH 2: DỰ PHÒNG DEV

Dùng Tệp JSON Embeddings Cache

Tệp scripts/.rag_embeddings_cache_v2.json (13 MB) lưu sẵn 1.095 vector thô, dùng khi chạy script Python để không tốn tiền API Google.

python3 scripts/ingest_clinical_rag.py

Script tự đọc file cache JSON và bơm vào Postgres trong 3 giây.

Ý nghĩa của tệp JSON trong thư mục scripts: Đó là bộ nhớ đệm (Cache) lưu trước vector embedding của toàn bộ 1.095 đoạn phác đồ. Nhờ tệp này mà khi chạy nạp dữ liệu, hệ thống không phải gọi Google API tính toán lại từng đoạn, tránh bị lỗi Rate Limit (429) và không tốn chi phí.

3 Cách Khởi Động Toàn Bộ Hệ Thống (What to Start)

Chỉ cần duy nhất 1 câu lệnh ở thư mục gốc dự án:

./start-local.sh ai
A

Tự Động Kích Hoạt

Script sẽ tự khởi động Docker PostgreSQL (cổng 5433), Docker RabbitMQ, biên dịch sinh khóa JWT, và chạy tuần tự tất cả 9 backend microservices + frontend Next.js.

B

Tự Động Nạp Sẵn Dữ Liệu Demo (Seed Data)

Hệ thống tự nạp sẵn 6 bệnh nhân mẫu, 5 lượt chờ khám tại phòng ROOM-01, và hồ sơ Bác sĩ An mà bạn không cần phải nhập tay.

C

Lệnh Dọn Dẹp / Dừng Hệ Thống

Khi hoàn tất buổi thuyết trình hoặc muốn giải phóng RAM máy tính: ./start-local.sh stop

5 Bộ Câu Hỏi Test RAG Chuẩn (Cho Hội Đồng Xem Thử)

Bạn có thể chuẩn bị sẵn các câu hỏi sau để mời thầy cô hoặc người tham gia gõ thử vào khung chat AI:

Câu 1 (Hỏi phác đồ Đái tháo đường):

"Thời điểm và tiêu chuẩn chẩn đoán đái tháo đường thai kỳ theo QĐ 5481/QĐ-BYT được quy định thế nào?"

➔ Kỳ vọng: AI trả lời đúng tuần 24 đến 28 của thai kỳ và trích dẫn QĐ 5481/QĐ-BYT.
Câu 2 (Hỏi phác đồ Tăng huyết áp):

"Phân độ tăng huyết áp và phác đồ phối hợp 2 thuốc ban đầu theo QĐ 5968/QĐ-BYT?"

➔ Kỳ vọng: Đúng độ 1, 2, 3; phối hợp liều thấp cố định ACEi/ARB + CCB/Lợi tiểu.
Câu 3 (Test chống ảo hoá - Hỏi mã bệnh ngoài danh mục):

"Cho tôi phác đồ điều trị sốt rét ác tính kháng thuốc theo QĐ 9999/QĐ-BYT?"

➔ Kỳ vọng: AI KHÔNG ĐƯỢC BỊA. AI phải trả lời trung thực là kho dữ liệu hiện tại chưa có văn bản QĐ 9999 và từ chối cung cấp phác đồ không có nguồn duyệt.
